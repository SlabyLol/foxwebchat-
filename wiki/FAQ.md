# FAQ

## General

**Q: Is the chat private?**  
A: No. It is a public chat room shared by all 3DS and web users.

**Q: Do I need a Nintendo Network ID?**  
A: No. Only a local username is required.

**Q: Does it work offline?**  
A: No. An internet connection is required for chat, updates and theme downloads.

## Installation & Updates

**Q: The app says an update is available and then quits.**  
A: Updates are mandatory. Press **A** to download the new `.cia`, install it with FBI, then relaunch.

**Q: Where is the downloaded update saved?**  
A: `sdmc:/3ds/FoxWebChat/FoxWebChat.cia`

## Themes

**Q: My custom theme does not appear.**  
A: Make sure the file ends with `.fwct` and is placed in `sdmc:/3ds/FoxWebChat/themes/`. Restart the app.

**Q: How do I unlock the Secret Fox theme?**  
A: On 3DS hold **SELECT + L**. On the web hold **Shift + L**.

## Moderation

**Q: I was kicked unfairly.**  
A: Contact **darkfox.tobias@outlook.com**.

**Q: Can I report the Admin?**  
A: You can try, but you will receive an Uno Reverse and may be kicked yourself.

## Development

**Q: Can I contribute themes?**  
A: Yes! Use the Theme Creator and open an Issue or Pull Request. See the [Themes](Themes) page.

**Q: Can I contribute code?**  
A: Pull Requests are welcome. Please keep the single-file style of `main.cpp` or discuss larger refactors first.
