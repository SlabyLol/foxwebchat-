# Admin & Moderation

## Becoming Admin

Enter the special admin code as your username when joining.  
(The exact code is embedded in the source – only the developer / trusted moderators should know it.)

Once joined as admin you will see **(ADMIN)** next to your name and gain access to the Admin Panel.

## Admin Panel

Press **B** to open/close the Admin Panel.

### Available actions

| Action | Button | Description |
|--------|--------|-------------|
| Kick user | **X** (on a report) | Adds the reported user to the kicks list |
| Clear all reports | **Y** | Deletes every report |
| Clear all messages | **L** | Wipes the entire chat and posts a system message |
| Unban all | **R** | Clears the entire kicks list |

## Reporting

Any user can report a message:

1. Select the message with D-Pad.
2. Press **Y**.
3. Enter a reason.

### Protection against reporting the Admin

If a user tries to report the Admin, an **Uno Reverse** is applied:

- The reporter themselves is reported instead.
- On the web version they are also immediately kicked.

## Kick System

- Kicked users see a full-screen “You have been kicked” message.
- The kick status is checked periodically against Firebase.
- Only an admin can remove kicks (Unban All or delete individual kick data on the web panel).
